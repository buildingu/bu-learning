Project One
This portfolio website was built using Bootstrap 5. I used the grid system to create a responsive layout that works on all screen sizes. The navbar is fully responsive with a hamburger menu on mobile, and the hero section features a call-to-action button styled with Bootstrap classes. The About and Projects sections are structured using rows and columns, and each project card includes a "View More" button that opens a Bootstrap modal (like this one). The contact form uses Bootstrap’s form controls and includes basic validation. I also added some custom CSS to tweak the design and colors.
